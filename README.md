# 日序 · Daily Order

每日计划与工作台静态版。

## Cloudflare Pages 部署

1. 打开 Cloudflare Dashboard。
2. 进入 Workers & Pages，选择创建 Pages 项目。
3. 连接 GitHub 仓库 3263067685/rixu2。
4. Production branch 选择 main。
5. Framework preset 选择 None。
6. Build command 留空。
7. Build output directory 填英文句点：.
8. 点击部署。

## 数据说明

数据保存在当前浏览器的 localStorage 中。手机和电脑的数据相互独立；清除浏览器网站数据会删除已保存的计划。
